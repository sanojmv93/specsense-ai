# specsense-ai
Conversational Product Insight Generator (GenAI Project)

Technologies: Python, Gemini (LLM), Prompt Engineering, Streamlit, Pydantic, Pandas

- Developed a GenAI driven tool that translates free-form queries into structured, explainable product recommendations.
- Leveraged Gemini (LLM) and prompt engineering to interpret vague user intents and match them with product data. 
- Built an interactive, modular UI with Streamlit for real-time product discovery. 
- Utilized Pandas and Pydantic to structure and validate product data, ensuring system scalability.
